How to install

  1. Download the pack. Click the button above and download the .zip from MediaFire. Keep it zipped.
  2. Open the pack folder. In Minecraft, go to Options → Resource Packs → Open Pack Folder.
  3. Add the file. Move the downloaded .zip into the folder that opens.
  4. Activate it. Select SNYDER in the list, move it to the right side, and click Done.
